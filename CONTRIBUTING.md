# Contributing to sondfree

Thank you for your interest in contributing to sondfree! We appreciate your help in making this project better.

## How to Contribute

- **Ideas and Discussions:** If you have ideas, suggestions, or questions, please open an issue to start a conversation.
- **Documentation Improvements:** Since this project is just getting started, improving documentation is a great way to contribute.
- **Pull Requests:** Feel free to fork the repository, make your changes, and submit a pull request. We will review and discuss it with you.

## No Build or Test Suite Yet

Currently, there is no build or test infrastructure. Contributions related to documentation or project planning are especially welcome.

## Communication

Please use GitHub issues and pull requests for all discussions and contributions.

---

We look forward to collaborating with you to make sondfree a great platform for independent artists!
